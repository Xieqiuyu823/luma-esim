Luma eSIM 0.1.3

日常安装：Android 12+ 的 Root 设备请在 Magisk「模块」中安装 `Luma-eSIM-System-0.1.3-magisk.zip`，然后重启。

若下载器把 ZIP 当作预览文件，可下载内容相同的 `.bin` 副本，保存后将后缀改回 `.zip` 再安装。系统版「设置 → 高级」中的自动开启数据漫游默认关闭；启用后只对切换配置成功的对应 SIM 生效，不会开启移动数据，漫游可能产生运营商费用。

Release 附带普通版和 System 版 APK（Debug / Release）、Magisk Debug / Release 模块、对应 `.bin` 下载副本、源码包、安装说明、验证报告和 SHA-256 校验文件。APK 使用与前版相同的 9eSIM Community Key；签名证书 SHA-1：`D1C0F48B370E74D4EA4770ED4C3CD70A3198D31F`。
